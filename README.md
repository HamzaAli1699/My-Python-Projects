## Simple Python Calculator
A terminal-based calculator script (cal.py) that performs basic and advanced arithmetic operations based on user input.

### Features
This calculator supports the following operators:
* + : Addition
* - : Subtraction
* * : Multiplication
* / : Division
* ^ : Power / Exponentiation (num1 ** num2)
* % : Percentage Calculation ((num1 * num2) / 100)

### How to Run
1. Make sure you have Python installed.
2. Run the script using the terminal:
   bash
   python cal.py
   
3. Enter the first number, choose an operator and enter the second number to see the result.
